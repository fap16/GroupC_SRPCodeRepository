**Overview**

This repository implements a single-cell RNA-seq analysis pipeline based on Camp et al. (2015), aiming to replicate key clustering results from cerebral organoid data.

The workflow consists of four main stages:

1. Alignment of raw FASTQ reads using TopHat2  
2. Transcript quantification using Cufflinks (FPKM)  
3. Construction of a gene-by-cell expression matrix  
4. Downstream clustering and visualisation using Seurat  

Where exact replication was not possible (e.g. software constraints, incomplete methodological detail), reasonable approximations were implemented while maintaining consistency with the original study.

**Automated Batch Alignment (TopHat2)** 
**tophat_b1.sh**

Performs the alignment step of the pipeline, mapping raw FASTQ reads to the human reference genome (GRCh38) to generate BAM files. 
Workflow follows the approach described in Camp et al. (2015), using TopHat2 (v2.1.2), a splice-aware aligner. 
TopHat2 is executed in a legacy-compatible environment (Python 2.7) on a SLURM-managed HPC cluster.
Alignment is performed using a Bowtie2-indexed GRCh38 genome and a GENCODE v22 annotation file. 
The --no-novel-juncs flag is used to restrict alignment to annotated splice junctions, reducing  inclusion of unannotated splice variants and ensuring consistency with the supplied gene models.
To manage computational load, samples are processed in batches of 15 (~730 cells). 
Was significantally slow with each job taking around 2 and a half hours on average and the entire process took a week. 

**Transcript Abundance Quantification (Cufflinks)**
**cufflinks.sh**

Performs the quantification step of the RNA-seq pipeline, converting BAM files into normalised gene expression values (FPKM). 
Uses Cufflinks (v2.2.1). 
Cufflinks is run in reference-guided quantification mode using the -G flag. This suppresses novel transcript assembly and restricts quantification to the provided gene annotation.
Ensembl Release 80 (GRCh38) is used as the reference annotation, provides GRCh38-compatible gene set that approximates the GENCODE v22 annotation used in the original study. 
Script includes basic error checking to ensure input BAM files are present before processing.
Uses multi-threading (-p 8) for efficient execution across the full dataset.

**Single-Cell Expression Matrix Construction** 
**merge.py**

Combines gene expression data from individual samples into a unified gene-by-cell expression matrix for downstream analysis. Implemented in Python using the Pandas library. 
Uses the glob module to locate all genes.fpkm_tracking files generated by Cufflinks. Extracts the sample identifier and reads gene-level FPKM values. 
Duplicate gene entries are removed to ensure consistent indexing across samples. 
Individual dataframes are then combined column-wise to construct a matrix, where rows = genes and columns = individual cells.
Missing values filled with 0s to produce a complete matrix suitable for analysis in Seurat.  

**Single-Cell Downstream Analysis & Visualisation**
**Fig3D_3E_3F.R**

Final stage of the pipeline, using Seurat for clustering, cell-type identification, and visualisation of single-cell RNA-seq data. 
The workflow integrates the FactoMineR package for Principal Component Analysis. 
Gene contributions to the first 15 principal components are evaluated using the dimdesc function, and a subset of genes (up to 50 per PC) is selected 
to approximate the feature selection strategy. 
Dimensionality reduction is performed using t-SNE with a low perplexity setting (5), enables visualisation of transcriptionally distinct cell populations. 
Graph-based clustering is applied, and cluster-specific marker genes are identified using Seurat’s receiver operating characteristic (ROC) test based on classification performance (AUC). 
Generates visual outputs corresponding to key analyses in the original study, including cluster visualisation and marker gene expression patterns.
Used to assign biological identities to clusters (e.g. forebrain, midbrain–hindbrain, mesenchymal populations) and to compare organoid-derived samples (r1–r4) with fetal tissue.
